# Подготовка к публичному запуску

Проверено 29 сентября 2026. Публичное развёртывание не выполнено; ключ OpenAI и Railway отложены владельцем. Исправления этого этапа не означают готовность всех запланированных сервисов.

## Исправлено и подключено

- Прокрутка: общая блокировка для комнаты, диалогов и мобильного меню. Закрытие вложенных окон больше не оставляет `body` заблокированным. При переходе к широкому экрану мобильное меню закрывается. Escape обрабатывает верхний диалог, фокус возвращается без прыжка страницы.
- Рейтинг: демонстрационные компании заменены опубликованными карточками из PostgreSQL. Сортировка числовая, по месячной выручке в одной валюте. Черновики и приватные проекты не участвуют. Данные выручки не верифицированы; это явно указано.
- Уведомления: реальные приглашения и текущие статусы модерации, переход в рабочий раздел, отметка прочтения на устройстве. Нет писем, push или архива событий.
- Прогресс: XP и уровни считаются по завершённым попыткам; уровень — каждые 500 XP. Добавлен остаток до следующего уровня и переход к истории. Кампания и достижения уже использовали историю, демонстрационных наград там нет. Черновик и знакомство с гидом не дают XP. Серверное завершение одной сессии не дублирует награду; новая завершённая попытка её даёт.
- Команды, приглашения, публичные карточки и админка уже имеют серверные действия. Совместное выступление в реальном времени — отдельная запланированная функция.

Демонстрация питча на лендинге и учебные слайды без загрузки файла остаются обозначенными примерами, а не личными результатами игрока. Голоса панели — нейтральная браузерная озвучка.

## Что требуется до открытого запуска

1. Подтверждение email и восстановление пароля. Сейчас приглашение проверяет совпадение адреса аккаунта, но владение почтой не подтверждено; перед открытием регистрации это нужно закрыть.
2. Удаление аккаунта и связанных приватных данных, правила хранения загрузок.
3. Подключение и проверка OpenAI на реальных RU/EN-питчах после предоставления ключа; учёт расходов, квоты и предельный бюджет. Текущий рабочий режим без ключа — анализ по правилам, отмеченный в интерфейсе.
4. Надёжная транскрипция для целевых браузеров. Сейчас доступен Web Speech API с ручным вводом и записью; живое распознавание разными устройствами и серверная транскрипция ещё не проверены.
5. Развёртывание: HTTPS, постоянное приватное хранилище, резервное копирование БД/слайдов с проверкой восстановления, мониторинг ошибок. Текущая архитектура рассчитана на один процесс API. Railway пока не настраивался.

Подписка, рекламные размещения, платежи, новости, хакатоны и совместный питч остаются в [бэклоге](BACKLOG.md). Это отдельные этапы продукта; кнопок оплаты, выдающих успешную покупку без провайдера, нет. Перед платным запуском нужны настоящие платежи и серверный учёт доступа/квот.

## Выполненные проверки

- `npm test`: правила, API и регрессия вложенных блокировок прокрутки.
- `npm run test:community`: изолированный PostgreSQL, права доступа, публикация, сортировка выручки, разделение валют, ноль/нераскрытая выручка и исключение неопубликованных изменений.
- `npm run test:prelaunch`: изолированный PostgreSQL и Chromium; реальные уведомления, прочтение после перезагрузки, рейтинг, переход к карточке, прокрутка после комнаты/диалогов и смены вкладок, мобильное меню, RU/EN, восстановление после ошибки API.
- `npm run test:guide`: учебный питч, восстановление и награда только после завершения.
- `npm run test:workspace`: временная SQLite для прежнего контура аккаунтов; сохранение питча/слайдов, серверная история во втором браузере, отделение гостевых данных. Это не проверка сообщества: его SQL рассчитан на PostgreSQL и проверяется отдельными сценариями выше.
- `npm run build`, `npm run typecheck`: сборка и TypeScript. Сборка предупреждает о крупном основном JS-файле; разбиение страниц на загружаемые по необходимости модули остаётся задачей производительности.

Браузерные отчёты сохранены в `artifacts/v14-*-verification.json`. Тестовые учётные записи создаются в изолированных БД и удаляются после проверки. Эти проверки не вызывают платный ИИ и не выполняют развёртывание.
