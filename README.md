# Pitch Arena

Веб-игра о питчинге стартапов. React 19, Vite, Lucide; русский и английский интерфейс. Светлый визуальный стиль с лавандовыми акцентами, оригинальными иллюстрациями и адаптивной картой мира.

## Архитектура и идеи

- [Архитектура проекта](docs/ARCHITECTURE.md): текущее устройство, границы модулей и предложенная серверная схема.
- [Банк идей владельца](docs/BACKLOG.md): 11 направлений развития, открытые вопросы и гипотезы монетизации. Статус — «На обсуждение», без начала реализации.

## Запуск

```sh
npm install
npm run dev
```

Адрес: http://localhost:5173. Сборка: `npm run build`, просмотр сборки: `npm run preview`, проверки логики: `npm test`.

## Игровой мир

- Восемь арен на интерактивной карте Земли с очертаниями стран, региональными фильтрами и автоматическим перемещением к выбранной точке на мобильном.
- Пять глав кампании: Свои люди → nFactorial Bootcamp → Арена Единорогов → Y Combinator → a16z. Все миссии также открыты для свободной тренировки.
- Арены располагаются в игровых локациях: Алматы, Москва, Сан-Франциско, Менло-Парк, Лос-Анджелес, Лондон и Дубай. Дом — условная точка старта, а не реальный адрес пользователя. Линии связывают карточки с географической точкой.
- Награды за завершение, бонус XP за результат, уровни каждые 500 XP, 1–3 звезды, пять достижений, отметки пройденных арен и лучший результат.
- Профиль, исходные транскрипты, ответы, результаты и награды сохраняются в localStorage. Старые результаты совместимы; прежние записи без поля XP учитываются как 100 XP.
- Рейтинг других стартапов — демонстрационные данные. Пользовательский прогресс показан отдельно.

## Выступление по этапам

1. **Подготовка.** Стартап, сумма раунда, презентация и длительность. Пресеты 1/2/3/5 минут; вручную 30–600 секунд. Две минуты для Арены Единорогов — игровое правило, а не заявление о регламенте мероприятия.
2. **Питч.** Микрофон либо текстовый ввод, таймер по реальному времени, камера по желанию, перелистывание слайдов. Панель слушает и не задаёт вопросов. Можно завершить раньше; после таймера запись автоматически останавливается.
3. **Транскрипт.** Пользователь проверяет и исправляет текст. Если распознавание недоступно, запись можно прослушать/скачать и внести текст вручную. Пустой транскрипт не анализируется.
4. **Разбор.** Пять тем с двумя проверяемыми элементами в каждой: клиент/проблема, продукт/действие, результат/контекст, доход/цена, ресурсы/цель. У каждого найденного элемента есть цитата, у пропуска — конкретная подсказка. Прогнозы и явные отрицания не считаются измеренным спросом; правила не понимают все языковые конструкции.
5. **Вопросы.** Пять основных вопросов с учётом текста, арены, уровня и суммы. После каждого ответа — разбор двух элементов. Если элемент пропущен, тот же собеседник может задать уточнение с цитатой ответа; максимум одно дополнительное уточнение за сессию. Оно дополняет исходный ответ, не создавая отдельного слота награды. Озвучивание — нейтральный голос браузера.
6. **Результат.** Балл по пяти темам, звёзды, XP, достижения, исходный питч, обратная связь по ответам и конкретная задача для следующей попытки. Кнопка «Улучшить питч» сохраняет название, сумму и лимит времени; слайды загружаются заново. Сравнение с предыдущей совместимой попыткой показывает общий балл, изменение исходного питча и каждой темы. Совместимость: одинаковые название стартапа, арена, лимит и версия оценки. Экспорт TXT включает диалог, задачу и сравнение. Незавершённая сессия не даёт наград.

Презентация: один PDF или до 20 JPG/PNG/WebP, до 20 МБ каждый. PDF использует просмотрщик браузера; изображения переключаются кнопками. Камера — локальный предпросмотр, без видеозаписи.

## Оценка и границы прототипа

Нет сервера, регистрации, облачного ИИ и анализа содержимого презентаций. Разбор — прозрачные локальные правила по тексту, а не семантическая оценка бизнеса.

Версия оценки 3: по каждой из пяти тем до 10 за исходный питч и до 10 за ответы (по 5 за найденный элемент). Объём текста и отдельные цифры не дают бонусов. Ответ на уточнение может заполнить пропущенный элемент; сумма по теме остаётся до 20. Правила ищут признаки в предложениях от четырёх слов и показывают найденные цитаты; это не проверка фактов или полноценное понимание смысла. Краткие формулировки и сложные отрицания могут распознаваться неточно.

Звёзды: 1 за завершение, 2 от 50 баллов, 3 от 80. XP: награда арены (100–400) + 5 за каждые полные 10 баллов. Повторные завершённые тренировки также дают XP. Достижение «Цифры говорят» в новой версии требует числового результата спроса и цены в ответах. Старые достижения сохраняются. Интерес панели — игровой индикатор, не решение об инвестициях.

Результаты предыдущих версий остаются читаемыми с исходной формулой и XP, но не участвуют в сравнении с версией 3. Локальный прототип сопоставляет проекты по нормализованному названию: переименование создаст новую точку отсчёта, а одинаковые названия разных проектов не различаются. Серверные ID проектов остаются будущим этапом.

Презентации и записи создаются как Blob URL, не загружаются на сервер приложения и не хранятся после выхода. Полная аудиозапись питча доступна на этапе проверки транскрипта. Web Speech API может передавать речь сервису распознавания браузера. Микрофон/камера требуют localhost либо HTTPS и разрешения пользователя. Google Fonts требуют интернета; карта и портреты включены в проект.

Средний балл на главной и лучший результат арены рассчитываются только по текущей версии оценки; нулевой балл отображается как 0, отсутствие новых результатов — без числового значения. История и заработанные XP сохраняются целиком.

## Проверка

- `npm test`: тесты чистой игровой логики, RU/EN-примеры, отрицания и прогнозы, отсутствие бонусов за объём/случайные цифры, уточнения, сравнение, переходы этапов и совместимость истории.
- `npm run build`: production-сборка Vite.
- `npm run test:browser`: воспроизводимый Chromium-сценарий двух попыток, обратной связи, сравнения, записи с тестовым микрофоном, экспорта, RU/EN, мобильной вёрстки и старых результатов.

Для первого браузерного запуска: `npx playwright install chromium`. Запустить `npm run build`, затем в отдельном терминале `npm run preview -- --port 5174`, после этого `npm run test:browser`. Можно переопределить `PITCH_URL` и `CHROMIUM_PATH`. Браузер использует изолированный контекст и тестовый микрофон; пользовательские сохранения не затрагиваются. Живой сервис транскрипции не проверяется.

Текущий отчёт: `artifacts/v3-verification.json`; снимки: `artifacts/v3-*.png`. Отчёт о 42 проверках предыдущей версии — `artifacts/v2-verification.json`; он сохранён как исторический результат, а не проверка текущей версии.
