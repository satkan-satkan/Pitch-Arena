# Pitch Arena

Веб-игра о питчинге стартапов. React 19, Vite, Lucide; русский и английский интерфейс. Светлый визуальный стиль с лавандовыми акцентами, оригинальными иллюстрациями и адаптивной картой мира.

## Запуск

```sh
npm install
npm run dev
```

Адрес: http://localhost:5173. Сборка: `npm run build`, просмотр сборки: `npm run preview`, проверки логики: `npm test`.

## Игровой мир

- Восемь арен на интерактивной карте Земли с очертаниями стран, региональными фильтрами и автоматическим перемещением к выбранной точке на мобильном.
- Пять глав кампании: Свои люди → nFactorial Bootcamp → Арена Единорогов → Y Combinator → a16z. Все миссии также открыты для свободной тренировки.
- Арены располагаются в игровых локациях: Алматы, Москва, Сан-Франциско, Менло-Парк, Лос-Анджелес, Лондон и Дубай. Дом — условная точка старта, а не реальный адрес пользователя. Линии связывают карточки с географической точкой.
- Награды за завершение, бонус XP за результат, уровни каждые 500 XP, 1–3 звезды, пять достижений, отметки пройденных арен и лучший результат.
- Профиль, исходные транскрипты, ответы, результаты и награды сохраняются в localStorage. Старые результаты совместимы; прежние записи без поля XP учитываются как 100 XP.
- Рейтинг других стартапов — демонстрационные данные. Пользовательский прогресс показан отдельно.

## Выступление по этапам

1. **Подготовка.** Стартап, сумма раунда, презентация и длительность. Пресеты 1/2/3/5 минут; вручную 30–600 секунд. Две минуты для Арены Единорогов — игровое правило, а не заявление о регламенте мероприятия.
2. **Питч.** Микрофон либо текстовый ввод, таймер по реальному времени, камера по желанию, перелистывание слайдов. Панель слушает и не задаёт вопросов. Можно завершить раньше; после таймера запись автоматически останавливается.
3. **Транскрипт.** Пользователь проверяет и исправляет текст. Если распознавание недоступно, запись можно прослушать/скачать и внести текст вручную. Пустой транскрипт не анализируется.
4. **Разбор.** Локальный поиск тем: проблема/клиент, решение, цифры, бизнес-модель, запрос. Доступен исходный фрагмент и найденные числа.
5. **Вопросы.** Пять вопросов с учётом текста, арены, уровня и суммы. Вопросы включают цитату из питча, найденные числа и уточнения недостающих тем. Озвучивание — обычный синтетический голос браузера, с выключателем и ручным повтором.
6. **Результат.** Балл, звёзды, XP, достижения, исходный питч и экспорт всего диалога в TXT. Незавершённая сессия не даёт наград.

Презентация: один PDF или до 20 JPG/PNG/WebP, до 20 МБ каждый. PDF использует просмотрщик браузера; изображения переключаются кнопками. Камера — локальный предпросмотр, без видеозаписи.

## Реальные прототипы

- **Арена Единорогов:** Оскар Хартманн, Антон Пронин, Виталий Полехин. Имена, роли и портреты с [официального сайта](https://arena.unicornfellowship.ru/).
- **nFactorial Bootcamp:** Арман Сулейменов. Портрет и профиль с [nFactorial School](https://www.nfactorial.school/); программа [nFactorial Incubator](https://2026.nfactorial.school/) служит контекстом игровой сцены.
- **Y Combinator:** Гарри Тан, [официальный профиль](https://www.ycombinator.com/people/garry-tan).

Все реплики придуманы для учебной симуляции и не являются цитатами или реальными инвестиционными решениями. Голоса реальных людей не клонируются и не имитируются. Нейтральная озвучка не выдаётся за голос прототипа. Проект не аффилирован с указанными людьми, фондами и программами. Остальные панели — вымышленные.

Адреса исходных портретов сохранены в [public/portraits/SOURCES.md](public/portraits/SOURCES.md).

## Оценка и границы прототипа

Нет сервера, регистрации, облачного ИИ и анализа содержимого презентаций. Разбор — прозрачные локальные правила по тексту, а не семантическая оценка бизнеса.

Балл: до 25 за найденные темы исходного питча; до 40 за пять ответов от 15 слов; до 25 за цифры в ответах; до 10 за объём исходного питча. Звёзды: 1 за завершение, 2 от 50 баллов, 3 от 80. XP: награда арены (100–400) + 5 за каждые полные 10 баллов. Повторные завершённые тренировки также дают XP. Интерес панели — игровой индикатор, не решение об инвестициях.

Презентации и записи создаются как Blob URL, не загружаются на сервер приложения и не хранятся после выхода. Полная аудиозапись питча доступна на этапе проверки транскрипта. Web Speech API может передавать речь сервису распознавания браузера. Микрофон/камера требуют localhost либо HTTPS и разрешения пользователя. Google Fonts требуют интернета; карта и портреты включены в проект.

## Проверка

- `npm test`: локальный разбор, контекстные вопросы, соответствие прототипов, совместимость старой истории, выдача наград.
- Production-сборка Vite.
- Chromium, 42 успешные проверки: полный цикл выступления, истечение таймера, остановка записи, запрет вопросов до разбора, сохранение текста и наград, экспорт, смена языка, загрузка изображений и мобильная карта. Проверены тестовый микрофон/камера и fallback без распознавания. Живой сервис транскрипции не проверялся.
- Отчёт: `artifacts/v2-verification.json`; снимки: `artifacts/v2-*.png`. Исходный отчёт и изображения первой версии сохранены отдельно.
