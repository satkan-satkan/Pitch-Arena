# Pitch Arena

Веб-игра о питчинге стартапов: карта арен, выступление перед игровыми инвесторами, вопросы после питча и прогресс основателя. React 19, Vite, Node.js 24, PostgreSQL; русский и английский интерфейс.

## Запуск

Требуется Node.js 24+ и PostgreSQL. Создать базу `pitch_arena` и указать `DATABASE_URL` в `.env`; на текущей машине база уже создана.

```sh
npm install
cp .env.example .env
npm run db:migrate
npm run dev:all
```

Открыть http://localhost:5173 — теперь это публичный лендинг. Игра: `/play`, каталог: `/startups`. Если Vite уже работает, запустить только API: `npm run dev:server`. `npm run dev` запускает клиент для гостевого режима. Готовая сборка: `npm run build && npm start`, адрес http://localhost:3001.

Для ИИ добавить `OPENAI_API_KEY` в `.env` и перезапустить API. В аккаунте включить «Разбор с ИИ-наставником» перед тренировкой. Без ключа доступен разбор по правилам; переключатель ИИ выключен. Ключ не попадает в клиент. Живой вызов провайдера в текущем окружении не проверен.

## Что работает

- 29 арен и 37 профилей инвесторов, локации в 12 странах, приближение карты к выбранному региону, пять глав кампании: Свои люди → nFactorial Bootcamp → Арена Единорогов → Y Combinator → a16z. Арены открыты и для свободной тренировки.
- Профиль, XP, уровни каждые 500 XP, звёзды, достижения, история и сравнение повторных попыток.
- Гостевая игра без регистрации. В аккаунте — личные проекты, серверная история, приватные слайды и восстановление прерванной тренировки, в том числе в другом браузере через тот же сервер.
- Музыка Inquisitive Groove из папки владельца. Включение и громкость в меню; по умолчанию выключена, во всей комнате питча и скрытой вкладке останавливается.
- Браузерная запись и транскрипция, ручное исправление текста, необязательная камера. Вопросы озвучивает нейтральный голос браузера.
- Необязательный ИИ-разбор текста и слайдов, формулирование вопросов и комментарии к ответам. При недоступности провайдера остаётся явно обозначенный разбор по правилам.

Рейтинг других стартапов пока демонстрационный. Команды, приглашения, публичные карточки, гид и первый учебный питч уже работают. Новости и хакатоны ещё не реализованы; идеи сохранены в [бэклоге](docs/BACKLOG.md).

## Путь игрока

1. **Подготовка:** проект, сумма, слайды и длительность 30–600 секунд. В комнате можно проверить микрофон и прослушать пробную запись до запуска таймера. Две минуты для Арены Единорогов — игровое правило, а не реальный регламент мероприятия.
2. **Питч:** микрофон или текст, таймер, слайды. Инвесторы слушают и не перебивают. Можно завершить раньше.
3. **Транскрипт:** проверка и исправление распознавания. При недоступной транскрипции можно прослушать/скачать запись и ввести текст вручную.
4. **Разбор:** пять тем, найденные цитаты и пропуски. Если включён ИИ — дополнительно содержательные замечания и анализ слайдов.
5. **Вопросы:** пять основных, максимум одно уточнение по ответу. После каждого ответа — обратная связь.
6. **Результат:** баллы, звёзды, XP, достижения и задача для следующей попытки. «Улучшить питч» переносит проект, сумму, время и задачу; слайды загружаются заново. Есть экспорт TXT.

Выход сохраняет черновик без награды. На карте можно продолжить или удалить его. Перезагрузка не продлевает таймер и не включает микрофон автоматически. Гостевые слайды и аудиозапись после перезагрузки не восстанавливаются; аккаунт восстанавливает слайды и этап вопросов.

## Стартапы и команды

В меню игры — создание личных и командных карточек, соцсети и приглашения с ролями. Одобренные карточки появляются в витрине «На радаре» на лендинге и главной игры. Карточки публикуются через модерацию в админке; выручка отмечена «со слов основателя». Питчи и слайды остаются приватными. Подробнее — [COMMUNITY.md](docs/COMMUNITY.md).

Аккаунт нужно зарегистрировать самому: на лендинге «Занять сцену» либо «Войти → Создать новый аккаунт». Готового логина/пароля нет. [Хранение данных входа и секретов](docs/ACCESS.md).

## Админка

Работают обзор, поиск пользователей и проектов, блокировка/разблокировка, роли, редактор существующих арен/инвесторов RU/EN, модерация стартапов и журнал изменений. Первого владельца назначают существующему аккаунту: `npm run admin:grant -- owner@example.com`. После обновления страницы появится пункт «Админка». Регистрация не выдаёт административных прав. Подробнее — [ADMIN.md](docs/ADMIN.md).

## Правила оценки

Версия 3: пять тем, в каждой до 10 за питч и до 10 за ответы. Каждый найденный элемент приносит 5 баллов и сопровождается цитатой. Уточнение заполняет пропуск основного ответа, не создавая дополнительного слота награды. Объём текста и отдельные цифры не дают бонусов. Прогнозы и явные отрицания отделяются от измеренного спроса, но правила не понимают все языковые конструкции и не проверяют факты.

Звёзды: 1 за завершение, 2 от 50 баллов, 3 от 80. XP: награда арены 100–400 + 5 за каждые полные 10 баллов. Новая завершённая попытка тоже даёт XP; повторный запрос завершения той же серверной сессии — нет. ИИ не назначает награды. Интерес панели — игровой индикатор, не решение об инвестициях.

Старые результаты сохраняют свои баллы и XP. Сравниваются попытки с одинаковыми ID проекта (у гостя — нормализованным названием), ареной, лимитом времени и версией оценки. Средний и лучший балл учитывают только текущую версию правил. Явный импорт гостевой истории не создаёт дублей и не помечает локальные результаты как серверно проверенные.

## Хранение и медиа

Аккаунты, проекты, сессии, каталог и аудит: PostgreSQL (`DATABASE_URL`). Исходная SQLite сохранена как резервная копия, сервер больше не использует её для работы. Приватные слайды: `.data/assets`. Это данные на машине, где запущен API; облачное развёртывание автоматически не создаётся. `.data` и `.env` исключены из Git. Гостевая история остаётся в localStorage.

Один PDF или до 20 PNG/JPG/WebP, до 20 МБ на файл. Сервер: до 40 МБ на сессию, 100 МБ на аккаунт. PDF использует просмотрщик браузера. При включённом ИИ текст, слайды и ответы отправляются OpenAI. Аудио не отправляется серверу приложения; Web Speech API может использовать сервис браузера. Камера — только предпросмотр. Микрофон и камера требуют localhost либо HTTPS и разрешения пользователя.

Карта и портреты включены в проект, Google Fonts требуют интернета. Исходник музыки: `sounds/main theme/Inquisitive Groove.m4a`; браузерная MP3-копия: `public/audio/inquisitive-groove.mp3`. Повторная подготовка — `npm run audio:prepare`. [Происхождение аудио](public/audio/SOURCES.md).

## Проверки

```sh
npm test
npm run build
npx playwright install chromium
npm run test:workspace
```

`test:workspace` сам поднимает временную БД/API и изолированный Chromium. Проверяет реальное воспроизведение музыки, регистрацию, приватные слайды, восстановление, завершение, вход со второго устройства и гостевой режим. Живой ИИ не вызывается.

Для гостевого сценария запустить отдельно `npm run preview -- --port 5174`, затем `npm run test:browser`. Он проверяет RU/EN, повторные попытки, запись с тестовым микрофоном, экспорт и мобильный интерфейс. Доступны `PITCH_URL` и `CHROMIUM_PATH`. Пользовательские сохранения не затрагиваются; живое распознавание речи не проверяется.

Новый каталог, создание карточек и микрофон: `npm run test:catalog`, `npm run test:expansion`. Источники и правила данных: [CATALOG.md](docs/CATALOG.md).

Дополнительные проверки: `npm run test:postgres`, `npm run test:admin`, `npm run test:community`, `npm run test:landing`. Перед коммитом — `npm run check:secrets`. Отчёт админки: `artifacts/v5-verification.json`.

Отчёты: `artifacts/v4-verification.json` (аккаунты/музыка), `artifacts/v3-verification.json` (гостевые сценарии). Снимки: `artifacts/v4-*.png` и `artifacts/v3-*.png`. Отчёт версии 2 сохранён как исторический.
