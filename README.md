# Pitch Arena

Интерактивный прототип веб-игры о питчинге стартапов. React 19, Vite, Lucide; интерфейс на русском и английском. Светлая палитра, оригинальные SVG-иллюстрации и адаптивная вёрстка.

## Запуск

```sh
npm install
npm run dev
```

Открыть http://localhost:5173. Production-сборка: `npm run build`; просмотр сборки: `npm run preview`.

## Что работает

- Обзор, семь тренировочных арен, фильтры по региону и сложности, поиск.
- Выбор индивидуального тренировочного инвестора.
- Редактируемый профиль и история завершённых выступлений в localStorage.
- Название стартапа и сумма инвестиционного раунда.
- Один PDF или до 20 слайдов-изображений, до 20 МБ каждый. Изображения можно перелистывать; PDF показывает встроенный просмотрщик браузера.
- Пять вопросов с учётом уровня арены; текстовые ответы, запись с микрофона и озвучивание вопросов.
- Распознавание речи через Web Speech API в поддерживающих браузерах. При отсутствии API или ошибке есть текстовый ввод. Запись аудио работает отдельно от распознавания.
- Необязательный предпросмотр камеры. Камера и микрофон выключаются при завершении/выходе.
- Игровой индикатор интереса, итоговая оценка, рекомендации, 100 XP за завершение и экспорт диалога в TXT.
- Проигрывание и скачивание последней записи ответа до перехода к следующему вопросу.

## Границы прототипа

Это клиентское приложение без сервера, регистрации и настоящего ИИ. Вопросы задаются по сценариям; содержимое презентации не анализируется. Уровень выбирается свободно: блокировки арен и платёжной механики нет.

Оценка прозрачная: до 50 баллов за ответы от 15 слов, до 25 за суммарный объём текста и до 25 за наличие цифр в ответах. Она не оценивает перспективность бизнеса или истинность утверждений. Интерес инвесторов — условный игровой показатель.

Рейтинг сообщества содержит пример данных; результаты пользователя показаны отдельно как локальный прогресс. Названия фондов и шоу используются для обозначения учебных сценариев, без аффилиации. Инвесторы — вымышленные персонажи; портреты с Unsplash иллюстративные.

Файлы презентации и записи создаются как локальные Blob URL и не отправляются приложением на сервер. Web Speech API может передавать речь провайдеру распознавания браузера. Микрофон и камера требуют localhost либо HTTPS и разрешения пользователя. Аудио и презентации не сохраняются после выхода из комнаты; история хранит текст ответов. Очистка данных браузера удаляет профиль и результаты. Google Fonts и Unsplash требуют интернета.

## Проверка

Production-сборка проходит. Браузерная проверка Chromium охватила 29 проверок: навигацию, фильтры, весь игровой цикл, сохранение после перезагрузки, язык, валидацию файлов, показ и перелистывание изображений, отмену выхода, экспорт текста, мобильную вёрстку, запись с тестового микрофона и камеру. Живое распознавание речи внешним сервисом не проверялось; проверен текстовый fallback. Итоги: `artifacts/verification.json`. Снимки интерфейса — в `artifacts/`.

## Следующий этап

1. Сервер с авторизацией, базой профилей и выступлений, общим рейтингом.
2. Серверный провайдер ИИ с анализом PDF, транскрипцией, адаптивными вопросами и содержательной оценкой. Ключи API должны оставаться на сервере.
3. Постоянное хранение записей по согласию пользователя и управление сроками хранения.
4. Более глубокая прогрессия, достижения, настоящие персонажи с согласованными правами на изображения и голоса.
