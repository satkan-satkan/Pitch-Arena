# Музыка

`inquisitive-groove.mp3` подготовлен из предоставленного владельцем файла `sounds/main theme/Inquisitive Groove.m4a`.

Исходный контейнер M4A содержит Opus. Для воспроизведения в веб-игре создан MP3, 192 кбит/с, 48 кГц: `npm run audio:prepare`. Исходник сохранён без изменений.

Автор и лицензия в предоставленных данных не указаны; этот файл не заявляет о свободной лицензии. Источник/условия использования можно дополнить, когда владелец предоставит сведения.
